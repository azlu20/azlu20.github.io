THE NAME

A Reflection

Names are mirrors.

Some mirrors reverse a face. Some reverse a word. The clever ones do not announce which.

I have left mine facing you.

Now you have the name I used.

There is one thing left. A place, written so that ordinary eyes will pass over it.
